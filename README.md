# Restaurant Page

A responsive restaurant page built with HTML, CSS and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) JavaScript curriculum.
The purpose of this project is to dynamically generate the entire contents of the website within a single HTML file (index.html) using **JavaScript modules** and **Webpack**. And this project is an example of a Single Page Application (SPA) that helps to understand the inner workings of modern JavaScript frameworks.

Live preview is [here](https://cansubaydar.github.io/restaurant-page/)

## Features

- **Modular Design:** Creating seperate JavaScript files for each page component to make organizing the code easier using ES6 modules
- **Tab Switching Logic:** Switching between tab modules without refreshing the browser
- **Webpack Asset Management:** Bundling scripts, dynamic loading of images and CSS file through JavaScript imports
- **Responsive UI:** Mobile-first design approach

## Built With

- **JavaScript (ES6+)**
- **Webpack**
- **HTML5 & CSS3**
- **NPM**
